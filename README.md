# Modern phpinfo

## Overview (English)
A refreshed presentation for the built-in `phpinfo()` output with a calming blue-to-green gradient skin. The single-page layout removes legacy styling, highlights hover states without flicker, and adds a subtle pointer glow for a modern diagnostics view.

### Highlights
- Cleans default `phpinfo()` markup and wraps sections in a glassmorphism-inspired card.
- Responsive CSS without external font/CDN dependencies.
- Lightweight TypeScript enhancements compiled to vanilla JavaScript for hover feedback.

### Quick Start
1. Serve the directory with PHP, e.g. `php -S localhost:8000`.
2. Visit `http://localhost:8000/index.php` to inspect your environment.

## Überblick (Deutsch)
Eine erneuerte Darstellung der PHP-Funktion `phpinfo()` mit sanftem Farbverlauf von Blau nach Grün. Die Einzelseite entfernt veraltete Styles, setzt schimmernde Hover-Effekte ohne Flackern ein und bietet einen modernen Blick auf Serverdiagnosen.

### Merkmale
- Bereinigt die Original-Ausgabe von `phpinfo()` und kapselt Bereiche in einer transparenten Karte.
- Responsives CSS ohne externe Schriftarten oder CDN-Abhängigkeiten.
- Schlanke TypeScript-Helfer, die zu JavaScript kompiliert werden und Hover-Zustände hervorheben.

### Schnellstart
1. Projektordner mit PHP starten, z. B. `php -S localhost:8000`.
2. `http://localhost:8000/index.php` aufrufen, um Ihre Konfiguration zu prüfen.
